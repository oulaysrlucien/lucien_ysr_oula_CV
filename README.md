# CV web - Lucien D.

CV web statique moderne, premium et responsive pour un Developpeur Salesforce / Integrateur API.

## Fichiers

- `index.html` : structure et contenu du CV
- `styles.css` : design responsive, format compact proche A4, styles print
- `script.js` : QR visuel, annee dynamique et petits comportements
- `assets/` : illustrations SVG modifiables

## Utilisation

Ouvrir `index.html` dans un navigateur.

Les textes, competences, experiences, liens et coordonnees sont centralises dans le HTML pour rester simples a modifier.
